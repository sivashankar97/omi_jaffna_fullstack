Oblate Province of Jaffna · Website CMS

CMS Guide & Map

Where every part of the website is edited, what each screen changes, and how to add text, photos and new entries.

Open the CMS
https://omi-jaffna-province.netlify.app/admin
Sign in with your CMS account. Ask the administrator for an account. Never share passwords.
The one rule to remember
The CMS menu follows the website menu. Open the page you want to change, edit it, save, then click View on website to check it.
What visitors see
Only entries that are Published. Changes show on the website straight away (refresh the page).
Photos
Every photo and logo can be replaced. Uploaded photos must be approved in File Uploads before visitors can see them.

Guide version: October 2026.

1. Quick start: change anything in 6 steps

  1. Find the page in the left menu under Website pages (same order as the website menu). Things that appear on several pages are under On several pages.
  2. Open a screen. The line "Shown on:" at the top says exactly where it appears on the website.
  3. Click the pencil on an entry to edit it, or Add … (e.g. "Add story") to add one.
  4. Change the text or photo. Each field label says where it shows. Empty text in page sections keeps the original wording.
  5. Set the status: Publication status = Published, Verified by Province = Verified, and a Last verified date. Then Save changes.
  6. Check it: click View on website (or the arrow icon on the row). It opens the exact spot on the page.
Tip: the Overview screen has a panel "Where to edit each page" with the same map as below. Click any item to jump to it.

4. How to …

Replace a photo or logo

  1. Open the entry and find the photo field (it shows a small preview).
  2. Click Upload a new image (JPEG, PNG or WebP, up to 12 MB).
  3. Go to File Uploads and approve the new image.
  4. Come back, set Published + Verified and Save.

Add a new item

Open the screen (e.g. News stories, Parishes, Oblate Priests) and click Add … (e.g. "Add story", "Add parish"). Fill the fields, choose Published + Verified with a date, and save.

Hide an item without deleting

Set Publication status to Draft and save. It disappears from the website but stays in the CMS.

Delete an item

Use the bin icon on the row. This cannot be undone.

Change the order

Each entry has Order on the website (1 = first). The CMS list is shown in the same order as the website.

Edit lists inside page sections

In page sections (Home, History, Charism, journey, Media photos, ministry pages), each list has Add, Move up / down and Remove buttons. Click a list item to open it.

See your change

Click View on website in the editor, or the arrow icon on any row. Map locations open the map with that pin selected.

Who can publish

Editors can write and save drafts. Publishers and Admins can publish. Admins manage accounts in Team & Roles.
